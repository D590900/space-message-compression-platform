# Third-party notices

This file tracks distributed **code and system-library** dependencies. Model weights are tracked separately in [`MODEL_LICENSES.md`](MODEL_LICENSES.md).

The lockfiles generated during implementation are the authoritative application-dependency inventory. Release CI generates an SPDX SBOM, and pull-request dependency review rejects newly introduced GPL/AGPL application dependencies. The exact release SBOM still requires review because base operating-system packages carry their own distribution obligations and automated classifiers can report multiple licenses for one Debian source package.
